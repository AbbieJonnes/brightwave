# BrightWave Digital Landing Page

## Project Overview

BrightWave Digital is a responsive landing page project for a fictional technology startup company.  
The website was designed to simulate a real-world business website with professional structure, responsive design, accessibility features, and SEO optimization.

The project demonstrates modern front-end development practices using HTML and CSS

# Features

- Responsive navigation menu
- Hero section with company introduction
- Services section
- About section
- Contact form with HTML validation
- Embedded media section
- Footer with social media links
- Mobile-first responsive layout
- SEO-friendly structure
- Accessibility support using ARIA labels and alt text

# Technologies Used

- HTML
- CSS

# Setup Instructions

## 1. Clone the Repository

```bash
git clone https://github.com/abbiejonnes/brightwave-digital.git
```

## 2. Open the Project Folder

```bash
cd brightwave-digital
```

## 3. Run the Website

Open the `index.html` file in your browser.


# Git Workflow

The project uses feature-based branching:

- main
- develop
- feature/navbar
- feature/services
- feature/contact-section
- feature/responsive-design


# Deployment

The project can be deployed using GitHub Pages.

## Deployment Steps

1. Push the project to GitHub
2. Open repository settings
3. Navigate to Pages
4. Select the `main` branch
5. Save changes

Your website will be available at:

```plaintext
https://abbiejonnes.github.io/brightwave-digital/
```
